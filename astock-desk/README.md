# 🏛️ 度小满赛道｜A股 AI 专业研判台

面向有自主判断能力的投资者，提供多源行情、五智能体研究、情景预测、风险审查和策略回测。零第三方依赖（纯 Python 标准库 + urllib）。

> ⚠️ **教育与研究用途，不构成投资建议。** 预测是基于公开数据的情景推演，不是收益承诺；系统**绝不自动下单**。A股实盘有滑点、T+1、政策与情绪风险，请独立决策、严控仓位。

## 它做什么
1. **实时盯盘**：东财/腾讯/新浪行情、日K、财务主要指标、主力资金流、个股新闻、大盘指数。
2. **多智能体投资委员会**（复现并扩展 [TradingAgents]）：
   - 📊 基本面分析师 · 📈 技术面分析师 · 🔥 情绪资金面分析师（三份独立视角，可分歧）
   - ⚖️ 首席交易员：综合三方，给方向/置信度/买入区间/目标价/止损/持有周期
   - 🛡️ 风控官：一票否决 + 仓位上限 + 硬性纪律
3. **边学边练**：每次结论汇总涉及的金融术语，点一下 AI 导师即时出「通俗讲解 + 实战用法 + 易踩坑」卡片。
4. **严肃回测**：均线/MACD/RSI 三策略，逐日模拟（含手续费+印花税），输出年化/最大回撤/夏普/胜率，并与「买入持有」对比——让你在信任任何信号前先看到它真实的赢面与亏损。

## 运行
```bash
cd astock-desk
export STEP_API_KEY="你的阶跃密钥"       # 或配置 DEEPSEEK_API_KEY
python3 server.py        # 读 $HOST:$PORT，默认 0.0.0.0:8000
```

Zeabur 部署时把 `STEP_API_KEY` / `DEEPSEEK_API_KEY` 配在项目 Variables，密钥不写入代码。

## 架构
| 文件 | 职责 |
|---|---|
| `lib/market.py` | 数据层：行情/K线/基本面/资金流/新闻/技术指标（多源兜底、重试） |
| `lib/llm.py` | OpenAI 兼容客户端：DeepSeek 主通道、阶跃备用通道、流式输出与自动降级 |
| `lib/agents.py` | 5 个 agent + 按需教学 `explain()` + 委员会编排 |
| `lib/backtest.py` | 规则策略回测引擎 + 指标 + 基准对比 |
| `server.py` | stdlib HTTP 服务，含 SSE 进度推送 |
| `web/index.html` | 深色盯盘看板（原生 JS + canvas，无 CDN） |

## 已知取舍
- K线为新浪**不复权**日线（高股息股回测略有偏差）；周月线走东财前复权。
- 回测为教学级简化模型（收盘价成交、单票满仓/空仓），非撮合级；用于**校准预期**而非实盘策略。
- 分析师串行执行以规避代理在并发+长响应下的截断，单次委员会约 30–45s。

## 后续可加难度（创新方向）
- 多空辩论轮：让看多/看空 agent 互相反驳再由交易员裁决（TradingAgents 的 debate 机制）。

- 自选股组合盯盘 + 每日定时晨报（可用平台 cron）。
- 龙虎榜/北向资金/行业板块联动等更多数据维度。
